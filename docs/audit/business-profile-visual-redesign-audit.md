# Business Profile Visual Redesign Audit

## Section classification

| Previous visible section | Classification | Result |
| --- | --- | --- |
| Shell update/profile directory card | Navigation shortcut, explanatory noise | Hidden on canonical Business Profile route |
| Business identity / Profile sections headings | Duplicate status / explanatory noise | Removed from visible route |
| Business details form | Business identity, contact details, registered details, output visibility | Preserved in Details tab |
| Branding | Branding | Preserved in Brand tab with richer previews |
| Finance and tax defaults | Finance/tax defaults | Preserved in Finance & tax tab |
| Regional controls inside details | Regional defaults | Moved into Regional tab |
| Appearance and layout tools | Application preference / non-profile content | Hidden on Business Profile route |
| Large Open-card matrix | Navigation shortcut | Replaced with compact related-settings link row |

## New structure

Business Profile now presents:

- compact identity summary;
- one header-level saved/dirty indicator;
- one save action;
- tabbed Details, Brand, Regional, Finance & tax panels;
- compact related settings links.

The route remains the existing Settings route and uses the existing tenant settings source of truth.
