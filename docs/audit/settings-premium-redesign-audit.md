# Settings Premium Redesign Audit

## Scope

Audited `/dashboard/settings` and legacy settings deep links.

## Canonical Ownership

| Group | Canonical destination |
| --- | --- |
| Business | Business Profile, Locations, Services |
| Work | Work & Job Sheet, Booking & Customer Pages, Job Output |
| People | Team & Access |
| Communications | Email & Notifications |
| Finance | Payments & Invoicing, tax shortcuts |
| Automation | Automations and custom fields |
| Application | Appearance & Layout, navigation preferences, product tour |
| Tools | Connected Tools, Developer Tools |
| Setup | Business Readiness, Guided Setup |

## Result

`/dashboard/settings` is now a concise directory/search page. It no longer embeds the Business Profile form by default. Legacy tab and section deep links still route to their existing settings owners.
