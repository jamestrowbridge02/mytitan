# Settings Source of Truth Map

Date: 2026-07-11

## Rule

Each setting has one canonical edit home. Related pages may show summaries and shortcuts, but must not duplicate full edit forms.

| Concept | Canonical Home | Related Pages |
| --- | --- | --- |
| Business profile | Settings -> Business | Setup wizard summary |
| Locations | Locations | Booking settings shortcut |
| Staff and access | Team | Settings directory shortcut |
| Scheduling and rota | Team / Staff rota | Calendar summary |
| Booking rules | Bookings -> Settings | Setup wizard shortcut |
| Services | Bookings -> Settings / Services section | Public booking preview |
| Customer payments | Payments | Finance and booking checkout summaries |
| MyTitan subscription | MyTitan Account / Billing | Settings shortcut only |
| Customer email | Email & Notifications | Booking/email template shortcuts |
| Job sheet/form | Work -> Job sheet settings | Live Work setup shortcut |
| Automation | Automation | Command Centre summaries |
| Integrations | Connected Tools | Provider setup deep links |
| Developer tools | Settings -> Developer Tools | Platform diagnostics only when authorised |
| Readiness and technical evidence | Platform Admin / Operations | Tenant pages show safe summaries only |

## Redirects and Shortcuts

Legacy and related routes should continue to route users to the canonical home. Shortcuts should use clear labels and avoid creating duplicate save paths.

## Setup Wizard

The setup wizard should write through the same canonical APIs used by the destination pages.
